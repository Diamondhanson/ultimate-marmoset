# Brand assets

Ready-to-use files for social profiles, printing, and anything else off-site.
Everything here is served publicly, so you can also download them straight from
the live site — e.g. `https://yourdomain.com/brand/profile-1024.png`.

| File | Size | Use it for |
|---|---|---|
| `logo.svg` | vector | Master logo. Scales to any size with no quality loss — send this to printers and sign makers. Transparent outside the green circle. |
| `logo-1024.png` | 1024×1024 | Logo with transparent corners, for placing over a coloured background. |
| `logo-512.png` | 512×512 | Same, smaller. |
| `profile.svg` | vector | Logo on a solid green square. |
| `profile-1024.png` | 1024×1024 | **Profile picture** for Facebook, Instagram, WhatsApp Business, X, Google Business. The square background means no transparent corners if a platform doesn't crop to a circle. |
| `profile-400.png` | 400×400 | Same, for platforms that want a smaller upload. |
| `facebook-cover.png` | 1640×856 | **Facebook page cover art.** Key content is centred so it survives Facebook's mobile crop. Works as an X/LinkedIn banner too. |

## Which one do I upload where?

- **Facebook page picture / Instagram / WhatsApp** → `profile-1024.png`
- **Facebook page cover** → `facebook-cover.png`
- **Anything printed** (business cards, signage, a crate sticker) → `logo.svg`

## Regenerating them

The cover is generated by the site itself, so it stays in sync with the brand
colours and fonts. With the dev server running:

```bash
curl -sS http://localhost:3000/brand-assets/facebook-cover -o public/brand/facebook-cover.png
```

The logo PNGs come from the SVG:

```bash
rsvg-convert -w 1024 -h 1024 public/brand/profile.svg -o public/brand/profile-1024.png
```

The browser favicon (`app/favicon.ico`, `app/icon.png`, `app/apple-icon.png`)
is built from the same `logo.svg`, so the tab icon, the phone home-screen icon
and these files never drift apart.
